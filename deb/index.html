rchat apt repository

Add it once on Debian or Ubuntu:

curl -fsSL https://bestusecase.github.io/rchat/deb/rchat-archive-keyring.gpg \
  | sudo tee /usr/share/keyrings/rchat-archive-keyring.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/rchat-archive-keyring.gpg] https://bestusecase.github.io/rchat/deb stable main" \
  | sudo tee /etc/apt/sources.list.d/rchat.list
sudo apt update && sudo apt install rchat

Installed packages upgrade automatically, or run sudo apt upgrade rchat.
